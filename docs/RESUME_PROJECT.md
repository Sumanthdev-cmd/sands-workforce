# Résumé project entry

**SandS Workforce — Workforce and Business Operations Platform**  
**Stack:** React, FastAPI, PostgreSQL, Redis, Android/Java, Firebase Cloud Messaging, AWS Lightsail, Caddy

- Developed a web and Android platform for employee/vendor attendance, task management, payroll preparation, shop inspections and management approvals.
- Integrated organisation-scoped APIs, role-based workflows, work-session location tracking and Android push notifications.
- Implemented financial approval flows with server-calculated amounts, action history and MD-gated disbursement recording; deployed the application with HTTPS on AWS Lightsail.
